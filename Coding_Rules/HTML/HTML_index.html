    理由:

    ブラウザが正しく読み込めますし、後から見ても分かりやすくなります。

  • 意味のあるタグ(セマンティックHTML)を使う

    セマンティックな（意味のある）タグを使う よく使うタグ：

    • < header> / < footer> : ページやセクションの上部・下部に使う
    • < nav> : メインのナビゲーションリンク用
    • < aside> : 補足情報やサイドコンテンツ用 （サイドバー、関連記事、広告、プロフィール、注釈など）
    • < main> : ページ内のメインコンテンツに使う（1ページに1回だけ）
    • < article> / < section> : 関連するコンテンツのグループ化や、独立した記事・投稿に使う
    • < figure> : 画像・図・コード例・グラフなどの自己完結したコンテンツ用

  • クラス名はBEMルールで分かりやすく付ける

    ラス名は「何のパーツか」「どこに属しているか」が分かるように付けます。
    その時に便利なのがBEM(Block / Element / Modifier)です。

    BEMの基本形:

    • block: 大きなかたまり(例:header、card、button)
    • element: blockの中の要素(例:title、image)
    • modifier: 状態やバリエーション(例:large、active)

    NG クラス名:

    • 何のboxか分からない
    • 他のページで再利用しにくい
